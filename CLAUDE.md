## Agent skills

### Issue tracker

Issues and specs are tracked in a tasklog workspace (`.tasklog/`) via the `tasklog` MCP tools. See `docs/agents/issue-tracker.md`.

### Triage labels

Default vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), applied as tasklog tags. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context. See `docs/agents/domain.md`.
